# Teaching Law

This repository is a GitHub Pages-ready teaching and research website for work on legal education, generative AI, geoeconomics, International Economic Law, Chinese law, and comparative legal method.

The public site is built from the workspace into `public/`. It publishes a static homepage, article abstract, project method, and a sanitized corpus explorer. Private local curation notes, AI drafts, unpublished student materials, generated Word files, and Google Drive links are not included in the public Pages artifact.

## Publish on GitHub

The repository name is expected to be `teaching`.

1. Push the repository to GitHub on the `main` branch.
2. In GitHub, open **Settings -> Pages**.
3. Set **Source** to **GitHub Actions**.
4. The workflow in `.github/workflows/pages.yml` builds and publishes `public/`.

After deployment, the site will normally be available at:

```text
https://<your-github-username>.github.io/teaching/
```

## Local Preview

Use Node.js 20 or newer.

```bash
npm run build:site
npm run dev
```

If `npm` is unavailable but Node.js is installed, generate the static data directly:

```bash
node scripts/build_site_data.mjs
node server/index.mjs
```

Then open:

```text
http://127.0.0.1:4173
```

## Public Data Boundary

- `data/sources.json` is the internal source index used to build the public corpus metadata.
- `public/data/site-data.json` is generated by `npm run build:site`.
- The generated public data omits Drive URLs, NotebookLM URLs, local curation notes, and AI drafts.
- GitHub Pages deploys only `public/`.

## Local Workspace

The local server still provides the existing API boundary for internal work. It serves static files from `public/` and keeps API access on `127.0.0.1`.

Optional AI drafting remains local and requires:

```bash
OPENAI_API_KEY=...
OPENAI_MODEL=gpt-4.1-mini
```
